# My Favorite Series: Stranger Things
## Overview
A thrilling Netflix sci-fi drama set in the 1980s in the fictional town of Hawkins, Indiana.

### Why I Love It
* **The Nostalgia:** The 80s music, fashion, and cultural references are perfect.
* **The Characters:** Great character development, especially Steve Harrington and Dustin.
* **The Mystery:** Every season introduces a compelling new threat from the Upside Down.

### Key Details
* **Genre:** Sci-Fi / Horror / Drama
* **Created By:** The Duffer Brothers
* **Favorite Character:** *Eleven* (played by Millie Bobby Brown)

> "Friends don't lie." — Eleven
